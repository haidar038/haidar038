# 💫 About Me
## Hi, I’m Haidar 👋

Founder of **Binary Verse** and a full-stack JavaScript product engineer from Ternate, Indonesia 🌴  
I design and ship **production-ready web apps** — from clean, pixel-accurate UI to scalable backend and deployment.

Over the last 3 months, I’ve built **8+ single-page applications (SPAs)** using a consistent modern stack, focusing on fast prototyping, real-world use cases, and maintainable code.

### What I do
- 🚀 Build modern SPAs with **React (Vite)**, **Tailwindcss + shadcn**
- 🔐 Handle auth, database, and backend logic with **Supabase**
- 🤖 Integrate **AI features** (OCR, image classification, chatbots) using **Groq + Llama**
- 🔁 Migrate legacy systems (Flask, WordPress) to modern web stacks
- 📦 Deliver end-to-end: design → code → deploy (**Vercel**)

### Background
Graphic designer turned developer — strong UI/UX instincts, product mindset, and fast execution. I care about clarity, usability, and shipping things that actually get used.

> *Design is not just what it looks like. Design is how it works.* — Steve Jobs

Always open to collaboration on impactful products, internal tools, and smart web solutions.
